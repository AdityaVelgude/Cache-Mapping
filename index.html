    Viva Quick Notes

    • Direct: each block has exactly one line → Index = Block No mod Lines.
    • Associative: a block can go in any line → no index, Tag = Block No.
    • Set-Associative: block maps to one set, any line in that set → Set = Block No mod Sets.
    • Address = Tag | Index/Set | Offset.
    • HIT = valid line with matching tag. MISS = block fetched from memory (FIFO replacement if full).
